# Font licenses

Both files are the Latin subsets served by Google Fonts, committed so that
builds do not need network access. Both fonts are licensed under the
SIL Open Font License, Version 1.1 (https://openfontlicense.org).

- `dm-sans-latin.woff2`: DM Sans 4.004, variable (wght 100-1000, opsz 9-40).
  Copyright 2014 The DM Sans Project Authors (https://github.com/googlefonts/dm-fonts).
- `jetbrains-mono-latin.woff2`: JetBrains Mono 2.211, variable (wght 100-800).
