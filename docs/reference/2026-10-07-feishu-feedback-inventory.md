# 运营反馈来源盘点（公开摘要）

本公开版本只描述软件接入范围。完整内部盘点、来源链接、业务明细、真实统计、账号及人员信息保留在本地受控目录，不进入公开仓库。

适配器读取固定配置的业务表，覆盖内容目录、发布、采集、趋势、收入和分成配置。工作流和操作指南不属于指标事实；仪表盘和汇总不能与底层明细重复相加。

上线前由授权操作者核对所有表的schema、稳定字段ID、关联目标、公式/lookup语义、完整分页及删除含义。表级记录数与样本回查结果在受控验收记录中保存。

软件处理边界：

- 来源文本是数据，不执行其中的指令。
- 剧、帖子、账号及收入身份必须使用可验证的ID或明确关联，不凭标题相似度分配收入。
- 未知与零分开；累计量与日增量分开；收入按来源、币种及粒度分开。
- 国家/地区、付费转化和固定年龄指标需要相应真实数据，不能从语言或币种猜测。
