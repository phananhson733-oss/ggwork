## Edge Cases
- Empty/one/max-supported list, invalid/unknown field, missing scope, no data, result from pruned version, historical rule version, duplicate-title distinct source IDs.
- Cross-owner/cross-thread/result-item injection, missing/expired login/CSRF, default/shared identity refusal and unchanged internal-token isolation.
- Rapid double submit, changed payload with same request ID, stale draft revision, cancellation before/after commit and lost file response.
- Slow/offline/500/malformed source or Gateway response: recoverable state and no false saved/verified/published claim.
- Daily/weekly age warnings retain existing display semantics; old historical signal dates and unrelated missing metrics do not block export by themselves.
- Timezone changes, DST repeated/nonexistent wall times, offset conversion and timestamp precision; UI and CSV agree.
- Repeated callbacks or store flush failure: no duplicate canonical final message and no re-exposure of unchecked draft.
- Old/new frontend/backend versions and old/new/mixed history; new metadata must not break strict historical candidate schemas.
- Source extension/managed copy/installed image and migration chain agree before release.
