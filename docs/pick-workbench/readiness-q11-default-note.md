# Q11 默认排除已选的模型说明修正

2026-10-05 真实 baseline 的 Q11 要求 5 部英语剧，YouTube 规则允许且确认在架，未知不纳入；没有匹配时解释原因，不放宽条件。预锁定条件沿用 `exclude_selected=true` 默认值，但实际模型主动传了 `false`。即使该 QA 身份清单为空、数量仍为 0，这次意图检查的 **FAIL 保留**，不能按结果相同改判通过。

本次仅收紧工具 schema 中 `exclude_selected` 的字段说明：默认 true；仅用户明确要求包含已选或不排除已选时设 false；渠道/在架条件不构成关闭个人排除的授权。筛选算法、条件形状和合法的显式 false 行为不变。

定向测试只能证明默认值、现有工具与提示词结构没有退化。该说明对模型行为的效果须由修改后的真实验收另行确认；当前不宣称 Q11 已修复通过，也不覆盖原 baseline 证据。
