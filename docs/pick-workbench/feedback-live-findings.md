# 来源验证要求（公开摘要）

完整实采报告保留在本地受控目录；公开文档不包含真实记录数量、账号、剧名、金额、人员、业务覆盖统计或内部来源链接。

已纳入软件测试的来源协议情况：

- 采集状态需明确区分complete、partial与失败；缺失标记会使对应旧指标失效。
- 已回填发布属于公开事实；未发布记录不当作零播放。
- 缺少自身Post ID时，仅在全部关联可解析、ID唯一且平台无冲突时补全。
- 链接可能采用Markdown形式；多链接或冲突平台保持未知。
- 持久化schema包含link、公式和lookup语义，并检测其变化。

上线验证需使用授权用户完整读取、核对终止页、验证稳定扫描、保存私有版本并抽取可回查样本。来源完整性与业务质量分别报告；本机授权不代表云端授权。

剧集身份映射和批准的新字段已按[映射维护说明](feedback-identity-mapping.md)实施，源读取升级为16表v2快照。真实本机授权双扫描、v1基线升级、本地发布及Agent分析路径已通过；来源质量仍按实采结果报告为partial。初始身份与外部ID候选保持待确认，没有把旧名称匹配转换成已确认归因。生产启用状态见最新发布记录。

日增量查询范围仍需另行设计。无法可靠归属的收益保持未知；没有实际地区分布时返回不支持。
